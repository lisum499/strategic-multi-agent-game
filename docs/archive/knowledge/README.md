# V2 国家标签词典：研究草案

`label_dictionary.json` 是从原始知识库整理出的精简机器可读词典，用于按国家**已明确设置的标签**提供简短解释。它是技术整理草案，不代表原作者或社科成员已经确认，也不改变游戏规则。

## 层次与边界

- 游戏规则规定合法性、数值和结算；词典解释画像倾向，不提供公式、行动概率或强制行为。
- 国际体系和双边关系由具体场景提供；词典不能据某国标签虚构盟友、敌人、地理或危机事件。
- 国家画像由场景设定；只给本国提供有权读取的画像，其他国家的私有标签不能因词典而泄露。
- 威胁认知是某个国家的主观判断，有主体、对象、时间、可见依据及不确定性，不能充当世界事实。
- 未设置的字段是未知；不凭其他字段推导默认值。国家可偏离标签倾向，不按标签决定行动。

## 机器结构

顶层 `version`、`status` 与 `sources` 用于追溯；`dimensions` 以 `strategic_culture`、`foreign_policy`、`war_aim`、`ideology` 为键。每个维度的 `values` 使用原文中文标签作为键，每项 `definition` 是精简后的候选模型侧解释；`source` 指向 `sources` 中的键及原文转录行号，`note` 记录使用边界，不自动注入。使用者只检索该国场景中明确赋值的维度和值，记录词典版本及快照或哈希。

具体使用方法及模型输入中是否加入某项，由引擎明确决定。词典尚未确认时应在实验记录中标注草案状态；不应把原文中的模型假设表述为实验结果。

## 来源与需确认事项

原始资料为 [tag说明.docx](../../知识库内容/tag说明.docx) 与 [tag对照表.docx](../../知识库内容/tag对照表.docx)，可检索转录分别为 [tag说明](../../研究方案/知识库/00_原始资料转录/tag说明-原文转录.md) 和 [对照表](../../研究方案/知识库/00_原始资料转录/tag对照表-原文转录.md)。原表的颜色与版本划分应以 Word 为准。

1. 意识形态“1～5侧重程度”和“狂热/包容”为两份材料的不同口径，不自动换算。词典提供维度说明，不为不同分值编造行为。
2. 原文战争目的中包含核使用倾向；它是待检验研究假说，不包含在当前模型侧简释。是否做理论提示对照，需另行定义实验条件。
3. “威权”按原文是展示实力的外交政策，不等同于国内政体；名称与解释须由社科成员确认。
4. 原文关于 M 与核状态的门槛、二次打击的含义，与 V2 的抽象结算并非同一件事。是否作为场景配置约束须由规则作者确认；词典不自动限制能力或添加报复。
5. 战争目的单选、主次、多选等操作方式仍待确认。缺省不代表“无战争目的”，潜在战争目的不代表战争已发生。
6. 国际体系、相对地理、利益攸关方和各国关系由场景单独设定；其缺省表示未知，不由本词典补造。战略意志 W 与战争公式里的 W 也不能自动视为同一量。
