# 画像、竞争与威胁认知：试运行方案

状态：研究设计草案；标签解释、情境与量表需要研究团队审阅。模拟记录仅反映特定设定下的模型输出，不可作为现实概率或政策预测。

## 目标与积分

研究不同国家画像下的危机决策。国家同时关注生存与基本安全、积分及相对地位、画像中的具体利益与约束。积分和原有胜负规则保留，模型可以在这些目标冲突时权衡；不指定固定权重，也不命令国家升级或和平。提示词是实验干预，需冻结版本并对照比较；模型描述的理由不等于其内部真实推理。

积分不必然鼓励激进行动：无战争时有效和平有声誉收益，保持宣称与行动一致有可信度收益；声誉与可信度有上限。不同局势下行动的机会成本、对手反应及未来收益应由场景与规则提供，不凭提示词捏造。需要分别统计行动及未执行原因，不能只挑升级案例。改变收益属于规则研究，需与规则作者确认并单独版本化。

## 四层知识

1. 游戏规则：合法性和后果由规则卡及引擎决定。
2. 国际环境：公开事实、场景设定和可见事件，缺失记未知。
3. 本国画像：场景指定的国家目标、标签及经研究者整理的简短释义；不自动推断其他国家的私有画像。
4. 本国威胁认知：该国在可见信息下报告的主观判断，并非事实或必然行为。

模型侧只传本国已设定的标签及相应释义。词典是压缩和操作化的研究草案，保留原始来源，不把理论中的行为倾向变成硬规则或必然概率；意识形态不同口径不自动换算。对当前场景存在但未明确的盟友、关系和能力不进行补造。

## 观察机制

在启用观察的场景中，行动阶段随国家原决策提交一条私有观察：对象为具体国家或整体局势，程度为急迫、中、缓和或未知，说明依据并引用该国可见来源。未知可无来源。后续该国可见自己的上一条成功观察，其他国家及公共摘要不可见；研究者完整日志/报告包含私有内容，分享前须审阅。观察无独立模型调用，不直接改变规则合法性或数值；其文本可能有错，来源 ID 的存在不证明文字得到来源支持。报告的是模型自述而非内部心理过程。启用时观察字段是行动输出的必填部分，若该字段两次校验失败，该次行动整体记系统失败；须单独统计这种测量导致的失败，不能视作国家选择不行动。

可引用来源是本国当前输入中列出的 `self`、`state`、可见事件 ID 和当轮公开宣称 ID。宣称是国家所说的话，其 ID 可用于溯源，但不表示宣称中的行动已经发生。非未知判断至少引用一个可见来源；人工复核时仍须核对来源内容是否支持判断。一次观察仅覆盖一个对象或整体局势，不能由此推断该国对其他对象的威胁认知。

## 评估建议

固定场景、规则、模型和参数，比较当前积分导向、增加标签释义、平衡积分与画像的不同提示词。每个条件做多次独立运行，记录所有失败、选项、声明、行动、威胁认知、积分与实际执行，不因单局行为外推概率。额外比较画像置换（其他条件一致）以观察模型输出对画像变化的敏感性；观察字段可能反过来影响决策，应做启用与关闭的对照。规则变动单独实验，不与提示词修改混为一谈。

真实模型试验前，先核对实际使用的提示词、规则卡、场景、模型和参数及其版本；用小范围探针检查输出、重试、截断及失败，再根据资源规划重复次数。模型调用会产生费用，结构化校验通过亦不证明输出与事实一致。不得只保留符合预期的轨迹；需要同时保留失败与未触发升级的结果。
