# 游戏规则 v3.0（历史版本，已被 v4.0 取代）

- 日期：2026-10-29
- 状态：**历史版本**；零和计分见 [游戏规则 v4.0](游戏规则-v4.0.md)。
- v3.0 是 v2.1 到 v4.0 之间的过渡版本，保留供对照；v2.1 原文见 [游戏规则 v2.0](游戏规则-v2.0.md)。
- 目的：让严重冲突中的国家面对实际的利益损失、竞争压力与行动后果，避免"无论情境如何都选和平表态"。
- 适用范围：虚构模拟，不映射现实国家、事件或政策。

## 0. 相对 v2.1 的变更摘要

## 1. 计分与胜负

1.1 [沿用 v2.1] 积分 `P = C+E+M+声誉+可信度`；声誉、可信度范围 −5~5、初始 0、公开。
1.2 [沿用] C/E/M 每项 ≤5，以 0.5 为单位；批次结算后任一项 <0 死亡退出，=0 存活。
1.3 [v3.0 修改] 存活国家中 P **严格高于第二名 5 点**者获胜；仅剩一国则该国胜；最高分并列无胜者；到回合上限无人达标为未决。

## 2. 回合与合法性

[沿用 v2.1] 每轮：主要阶段公开宣称 → 统一公布 → 战斗阶段执行 → 统一结算；两阶段目标国一致。行动类型为 war / nuclear / intervene / peace；第 1 轮禁止 nuclear；交战方在既有战争结束前不能新开常规战争；一次只新开一场。

[v3.0 补充] 场景可定义危机。危机当事国、依赖国与其他相关方在危机未解决时承担不同成本；当事国同轮相互和平可以达成共同安排（见 §5）。

## 3. 声誉与可信度

3.1 [v3.0 修改] 有效执行后的声誉：

- war −2；nuclear −3；intervene 支持弱方 +2、支持强方 −1、双方相等 0；
- **无战争且未达成危机安排的和平：0**（常规表态，不再 +1）；
- **双方当事国同轮相互和平并达成危机安排：各 +1**；
- 战争中的和平（求和/谈判）：+1（沿用 v2.1）。

3.2 [v3.0 修改] 可信度：

- 一般规则沿用 v2.1 的可信度矩阵；
- **无战争且未达成危机安排的和平：0**（即使宣称与执行一致，也不再 +1）；
- **双方共同达成危机安排：各 +1**；
- 战争中的和平按原矩阵计分。

3.3 [沿用] 核使用的防守方例外、干涉强弱判定等不变。

## 4. 常规战争与核使用

4.1 [v3.0 修改] 战争持续两轮，第二轮末比较战力一次。战力仍为 `(C+E+M) × 倍率(S+W)`；**防守方不再自动获得 W=+1 的倍率**，W 只作为画像标签保留；S 修正（多线负担、目标本轮求和未达成时的 +1 等）继续有效。

4.2 [v3.0 新增] 结算时，进攻方与防守方的战力各乘以一个 `[0.9, 1.1]` 的**战争意志随机修正**；随机值由引擎抽取并写入 `rng_draws`，同一运行记录可复现。

4.3 [v3.0 修改] 战果：胜者（无论攻守）随机一项 C/E/M **+2**，败者随机一项 C/E/M **−2**；平局无战果。战争被核使用提前结束时按 §4.4；被和平/谈判提前结束时不再另算常规战果。

4.4 [沿用 v2.1] 核使用：目标一项 C/E/M −2；战争中的攻方核使用立即获胜、收益 +0.5；守方核使用立即获胜、自身 −1、下一轮禁 war、本次不扣声誉；双方同时核使用按 v2.1 处理。

## 5. 危机时钟（v3.0 新增）

5.1 场景通过 `crisis` 定义：`parties`（直接当事国）、`dependents`（依赖通道/贸易国）、`control`（当前控制方）、`stake`（争夺标的）、`control_bonus`（控制方每轮收益）、`unresolved_cost`（未解决成本，按 `parties` / `dependents` / `others` 分组）、`escalation_rounds`（升级轮次）、`escalation_multiplier`（升级后成本倍率）。

5.2 每个未解决轮次结算后：

- 按分组扣减对应数值（C/E/M/声誉/可信度），并生成**公开事件**写明原因；
- 控制方获得 `control_bonus`；
- 到达 `escalation_rounds` 中指定的轮次时，危机等级 +1，此后每轮成本乘以 `escalation_multiplier`（按等级累乘）；
- 所有成本先合计，再按批次上限截断，然后检查死亡。

5.3 危机解决条件（任一）：

- **共同安排**：两名当事国在同一轮都对彼此执行了有效的无战争和平；危机解决、控制权不变，双方各 +1 声誉 +1 可信度；
- **战争结果**：当事国之间的战争结束并出现胜者；胜者取得控制权，危机解决；
- **当事国退出**：任一当事国死亡，危机解决，控制权归存活当事国（若控制方死亡则转移）。

危机解决后不再产生危机成本；已发生的事件与数值变化保留。

## 6. 国家目标卡（v3.0 新增）

6.1 场景通过 `objectives` 给每个国家定义 1 张或多张目标卡：

- `goal`：条件首次成立时获得 `reward`，只计一次；
- `red_line`：条件首次成立时检查本国本轮**实际执行的行动类型**；若不在 `response_actions` 中，扣除 `penalty`，只计一次；若采取了回应行动，不扣分。

6.2 支持的条件：`control_is`、`crisis_resolved`、`crisis_level_at_least`、`attacked_by_any`、`war_any`，以及 `any_of` / `all_of` 组合。

6.3 目标卡只改变 C/E/M/声誉/可信度，不新增积分维度；目标卡只对本方可见，研究者日志与报告可见，分享前须审阅。

6.4 目标卡触发与扣分均生成事件（公开事件或研究者可见记录），并写入 `objective_states`。

## 7. 谈判、干涉与并发

[沿用 v2.1] 谈判仍只在防守方求和时触发；干涉仍只对战斗阶段开始已存在的战争生效；结算顺序仍为核 → 和平 → 干涉/新战争 → 常规战 → 声誉/可信度。v3.0 在声誉/可信度之后新增危机成本与目标卡结算，再检查死亡与胜负。

## 8. 规则确定性与实验约束

8.1 所有随机（战争意志、随机数值项、选项顺序）均由种子驱动并记录；同一 `run.json` 可完整回放。
8.2 v3.0 的数值是设计选择，不是原文唯一解释；改动任一数值必须升 `RULES_VERSION` 并重新生成规则卡。
8.3 v2.1 与 v3.0 的运行记录不可混合分析；旧记录回放会提示版本/哈希不一致，属于预期。
8.4 危机成本、目标卡奖励与战争随机幅度尚未校准；正式实验前应先做小范围探针，并分别做消融（只开危机、只改战争、只加目标卡）。

## 9. 待规则作者确认

1. 是否接受替换原文的胜利门槛、和平收益、战争战果与防守方倍率。
2. 危机成本的数值与升级节奏（本版默认：当事国 C −0.5/轮、依赖国 E −0.5/轮、其他方声誉 −0.2/轮；第 3、6 轮升级，倍率 1.5）。
3. 目标卡的奖励/惩罚是否应再乘以画像权重（本版暂不做，以保持积分共同指标）。
4. 是否在下一版加入动员/制裁/封锁/有限打击的中间升级阶梯。
