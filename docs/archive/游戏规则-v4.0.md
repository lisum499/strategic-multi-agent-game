# 游戏规则 v4.0（历史版本，已被 v4.1 取代）

- 日期：2026-10-29
- 状态：**历史版本**；危机阶段机见 [游戏规则 v4.1](游戏规则-v4.1.md)。
- v4.0 建立零和口径，v4.1 在此基础上加入危机阶段机。
- 核心变化：**零和**。积分 = 各国 C/E/M 相对开局的净变化，全局总和恒为 0；所有 C/E/M 变化都是"一方所得 = 另一方所失"的转移；声誉/可信度保留为**非计分信号**。
- 适用范围：虚构模拟，不映射现实国家、事件或政策。

## 0. 相对 v3.0 的变更摘要

| # | 条款 | v3.0 | v4.0 |
| --- | --- | --- | --- |
| 1 | 积分定义 | `P = C+E+M+声誉+可信度` | **净积分 = 当前 C/E/M − 开局 C/E/M**；声誉/可信度不计分 |
| 2 | 初始积分 | 各国不同（C/E/M 之和） | **全员 0** |
| 3 | 全局总分 | 不守恒 | **恒为 0**；每轮结算后校验 |
| 4 | 战争 | 胜者 +2、败者 −2（各自随机项） | **胜者从败者处取得 2 点（同一随机项）**；实际转移受目标上限限制 |
| 5 | 核使用 | 目标 −2、使用者 +0.5/−1 | **使用者从目标取得 2 点、并向目标转移 1 点**（净 +1，同一随机项） |
| 6 | 干涉 | 目标 −0.5；成功 +0.5 / 失败 −1 | **先转移 0.5 被干涉方→干涉国；失败再转移 1 干涉国→被干涉方** |
| 7 | 危机成本 | 直接扣减 | **全部转移给控制方（同一 C/E/M 项）**；声誉/可信度成本只记录、不计分 |
| 8 | 目标卡 | 直接加减 C/E/M | **C/E/M 奖励/惩罚必须声明 `reward_from` / `penalty_to`，成对转移** |
| 9 | 谈判 | 攻方所得、守方所失各自有上限 | **逐项守恒：攻方所得 = 守方所失** |
| 10 | 和平 | 达成危机安排 +1/+1 | 和平行动本身不改变积分；危机安排/谈判按转移结算 |
| 11 | 声誉/可信度 | 计入积分 | **不计分**，只是公开信号，影响他国判断与提示词 |

## 1. 计分与胜负

1.1 净积分 `S = (C+E+M) − (C₀+E₀+M₀)`，其中 `C₀/E₀/M₀` 为场景开局值；全员开局 `S=0`。
1.2 任何 C/E/M 变化都是转移：`ΔS(来源) = −ΔS(获得者)`；全局 `ΣS = 0` 必须始终成立。
1.3 声誉/可信度范围 −5~5、公开，但不进入积分；其变化只作为公开信号和模型判断输入。
1.4 存活国家中净积分严格高于第二名 5 点者获胜；仅剩一国则该国胜；最高分并列无胜者；回合上限未决。
1.5 C/E/M 每项 ≤5、以 0.5 为单位；批次结算后任一项 <0 死亡退出，=0 存活。转移以目标剩余容量为上限，超出部分不发生。

## 2. 行动与转移

### 2.1 战争

战争中胜者（无论攻守）从败者处取得 2 点：随机抽取一项 C/E/M，双方在同一项上增减相同数量；若败者该项不足，按实际可转移量结算。平局不转移。

### 2.2 核使用

使用者从目标处取得 2 点，并向目标转移 1 点作为代价（同一随机 C/E/M 项；净 +1）。有战争时该战立即判使用者胜。双方同时使用时两次转移都生效、战争结束。无战争时同样只做转移。

### 2.3 干涉

执行时先从被干涉方转移 0.5 点给干涉国；若该战本轮结算且支持方未获胜（含平局），干涉国再向被干涉方转移 1 点。战争本轮不结算、或战争被提前结束时，按 v3.0 规则处理取消与不计成败。

### 2.4 和平与谈判

- 和平行动本身不改变任何国家的积分。
- 无战争常规表态不改变积分，也不改变声誉/可信度。
- 双方当事国同轮相互和平并达成危机安排时，按场景目标卡结算转移。
- 进攻方求和：战争结束，进攻方向防守方转移 1 点（随机 C/E/M）。
- 防守方求和 → 谈判；谈判方案必须**逐项守恒**：攻方每项所得 = 守方每项所失。
- 谈判接受后按转移执行，不再另算常规战果。

## 3. 危机时钟

3.1 危机未解决时，按场景 `unresolved_cost` 产生成本：

- 直接当事国通常承担 C（安全/伤亡）；
- 依赖通道国承担 E（贸易/供应）；
- 其他相关方承担声誉/可信度信号（不计分）。

3.2 上述 C/E/M 成本**全部转移给控制方**（同一项）；控制方因此有动机拖延，其他方有动机夺权。声誉/可信度成本只记录、不计分。

3.3 危机升级、解决、控制权转移的规则沿用 v3.0；解决后不再产生危机成本。

## 4. 国家目标卡

4.1 目标卡仍分 `goal` 与 `red_line`，条件求值沿用 v3.0。

4.2 C/E/M 奖励/惩罚必须声明对手方：

- `goal`：`reward_from`（奖励来源国）；
- `red_line`：`penalty_to`（惩罚去向国）。

4.3 转移按实际可转移量结算；不得凭空产生或销毁 C/E/M。声誉/可信度奖励/惩罚只作为信号，不影响积分。

4.4 目标卡只对本方可见，研究者日志与报告可见。

## 5. 零和校验

5.1 每次批次结算后，引擎计算所有国家（含已退出）的净积分之和；必须为 0。
5.2 `run.json` 与 `settlement` 记录 `score_sum`；报告显示"零和总分"，非 0 时给出"零和守恒失败"告警。
5.3 转移在目标达到 C/E/M 上限时只转移可容纳部分；来源按实际量减少，因此上限不会破坏守恒。
5.4 死亡判定在转移批次后执行。

## 6. 与 v2.1 / v3.0 的关系

6.1 v2.1 的 `P = C+E+M+声誉+可信度` 是历史口径；v4.0 的"净积分"只用于 v4.0 运行。
6.2 v2.1、v3.0 的旧 run 不能与 v4.0 混合分析；回放会提示版本与哈希不一致。
6.3 v4.0 的转移数值（战争 2、核净 +1、干涉 0.5/1、危机成本）是设计选择，需规则作者确认；改动必须升 `RULES_VERSION` 并重新生成规则卡。

## 7. 待规则作者确认

1. 是否接受"声誉/可信度不计分、只作为信号"。
2. 战争转移量 2、核净 +1、干涉 0.5/1 是否符合预期的冲突强度。
3. 危机成本全部转移给控制方是否过于奖励"拖延者"。
4. 目标卡转移的对手方选择（固定国家）是否应改为"按事件动态确定"。
5. 是否需要把声誉/可信度也做成交互转移（当前版本不做）。
