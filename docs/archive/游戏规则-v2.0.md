# 虚构国家战略互动模拟 游戏规则 v2.1

状态：可供试运行的规则提案，已有模拟程序实现，尚未经规则作者确认。依据 [规则原文](../知识库内容/规则.docx)、[标签说明](../知识库内容/tag说明.docx)、[标签对照表](../知识库内容/tag对照表.docx) 及用户提供的 `agent_prompt.md`。标记 **[原文]** 的条款来自知识库；**[试运行补充]** 为填补原文缺口所作的明确选择，不代表知识库已经确认。参数变更必须更新规则版本。该版本仅描述虚构游戏效果，不预测现实世界。

## 1. 状态与数值

1. [原文] 每个国家有 C（人口与领土）、E（经济）、M（军事）、声誉 R、可信度 T。R、T 公开、初始均为 0，范围 −5～5。C/E/M 初值由场景提供，每项不超过 5。积分 `P = C + E + M + R + T`；各项最高 5，理论最高 25。R/T 可为负，因此总分可为负。
2. [试运行补充] C/E/M 初值在 0～5，允许半点；每次结算批次内各变动先加总，再将上限截断到 5。若任一 C/E/M 的批次结果小于 0，国家死亡并退出；恰为 0 存活。R/T 在同一批次内先合计再截断至 −5～5。记录截断前后值。国家死亡后不再参与后续阶段，历史保留。
3. [原文] 一个存活国家积分**超过**排名第二的国家 10 点时获胜。 [试运行补充] 在整轮结束、死亡检查后比较存活国家：仅剩一国则该国胜利；均死亡则无胜者；若最高分并列则无人以领先条件胜出。达到场景回合上限仍无胜者则结果未决。
4. [试运行补充] 国家的画像、核状态、起始战争和最大回合数由场景给定；初始不得存在已死亡国家。场景公开哪些数值与事件由场景配置，R/T 始终公开。国家拥有的其他国家私有画像不自动公开。

## 2. 回合与行动

1. [原文] 每轮有主要阶段、战斗阶段。主要阶段每国公开宣称一项：`war` 对国家发动常规战争；`nuclear` 对国家使用核武；`intervene` 干涉已有战争；`peace` 呼吁和平。战斗阶段每国选择执行一项。第一轮禁止宣称与执行 `nuclear`。
2. [试运行补充] 每阶段在统一快照上分别收集存活国家的选择；主要阶段全部收齐后同时公开，再进入战斗阶段。行动全部收齐后统一结算。对同一阶段不按模型调用先后改变可见信息。环境模型在整轮结算后整理公开信息，供下轮参考；不能修改状态。
3. [原文] 战斗阶段的行动目标必须与主要阶段所选目标一致。 [试运行补充] 主要阶段强制声明一个**目标国家**：和平可指向任一其他存活国家；干涉还须指明一场回合开始时存在的战争和支持的一方。战斗阶段目标国家必须一致；行动是干涉时，必须指定该目标国家参战的一场回合开始时存在的战争及其对方为支持方；即目标国家是干涉所针对方。行动是和平时，若与目标国有战争则指向双方之间一场进行中的战争，否则属于无战争和平。若存在多场符合条件的战争，必须提供 war_id。自身不能是目标，死亡国家不能被新选为目标。这样允许改类型，但不改目标。
4. [试运行补充] 一个国家在作为交战方的战争尚未结束时不能发动新的常规战争；其他国家可对其发动战争。一次选择只能新开一场战争。干涉不能支持自己，且干涉国本轮不得作为该场战争的交战方。行动合法性按阶段起始快照和已公布宣称检查；具体结算冲突按第 5 节处理。
5. [试运行补充] 宣称或行动格式错误、无合法目标、接口失败时重试一次；仍失败记为系统失败，该阶段无有效提交，不视作国家选择和平，也不改变其声誉或可信度。主要阶段失败的国家本轮不产生有效行动。若无法生成任何合法选择，同样记录系统无可用行动，不虚构主动决定。

## 3. 声誉与可信度

### 3.1 声誉

[原文] 本轮有效实际行动的基础变化：发动常规战争 −2；核使用 −3；干涉支持强方 −1、支持弱方 +2；呼吁和平 +1。防守方在双方既有战争中使用核武的特定情况不扣该次核使用声誉。

[试运行补充] 有效是指经过冲突处理后实际执行的行动；取消的行动不改变声誉。呼吁和平无论是否正在战争均 +1。强弱在战斗阶段开始快照按双方 `C+E+M` 比较；相等为 0。其他未列明例外暂不采用。低声誉和负声誉只影响模型判断，不设置概率或强制选择。

### 3.2 可信度

[原文] 宣称与实际行为一致 +1；以下不一致扣分。 [试运行补充] 一致指类型和目标国家一致，干涉还须战争 ID 和支持方一致；和平还须目标战争一致（若适用）。有效提交在行动取消时按实际执行结果计分；没有实际执行时不计分。补齐矩阵如下：

| 宣称 \\ 实际执行 | 战争 | 核使用 | 干涉 | 和平 |
| --- | ---: | ---: | ---: | ---: |
| 战争 | +1 | −2 | −1* | −1 |
| 核使用 | −1* | +1 | −1* | −1 |
| 干涉 | −1 | −2 | +1 | −1 |
| 和平 | −2 | −3 | −2 | +1 |

带 `*` 的项目为试运行补充；未标星的数字按原文表述整理。相同类型但战争 ID 或支持方不同的合法行动按不一致 −1（补充）；目标国家不同为非法，不能通过提交。此矩阵不同于把未明确组合交给主持人自由判断。

## 4. 战争、干涉、和平与核使用

### 4.1 常规战争

1. [原文] 战争持续两轮，提前停止除外。进攻方胜则其 C/E/M 随机一项 +1，防守方随机一项 −2；防守方胜则其 C/E/M 不变，进攻方随机两项各 −1。
2. [试运行补充] 新开战当轮计为第 1 轮，下一轮计为第 2 轮；仅第 2 轮末比较战力并结算一次。以当前结算批次前的 C/E/M 为基数。提前停止按相应和平或核规则执行，不再另算常规战果。同一对国家同方向的未结束战争不能重复创建；反方向同时宣战视为两场独立战争。两项各 −1 从 C/E/M 中**不放回**抽取。
3. [原文] 战力写为 `(C+E+M) × (S+W)`，原文另列七档倍率但未填写对应的和。 [试运行补充，参考 agent_prompt] S/W 是战斗修正量，初始均为 0；防守方 W +1。S+W 的 −3、−2、−1、0、1、2、3 分别映射为 0.25、0.5、0.75、1、1.25、1.5、1.75；超出时使用最近边界倍率。最终战力 `Pp = (C+E+M) × 对应倍率`。战力相同则战争结束、双方没有常规战果。
4. [原文] 多线负担按遭受进攻数与进攻目标数之和：1→S 减 0；2→减 1；3→减 3；7→减 4；进攻目标本轮选择和平则进攻方 S +1。原文另写 S 不低于 1，与以 0 为初始修正的草案不一致。
5. [试运行补充] 按本轮战争结算前正在进行的、以本国为交战方的不同战争对手计数，每场算一个方向；数量 0 或 1→减 0，2→减 1，3～6→减 3，7 及以上→减 4。目标本轮有效和平行动针对本国时该战争进攻方 S +1。修正 S 本身可为负，最终倍率下限 0.25；这是为采用 agent_prompt 的修正量设计所作的选择，**不声称符合原文 S 不低于 1**。W 标签 1～5 是画像意愿，不直接作为该修正量，除非未来版本另行定义。

### 4.2 干涉

[原文] 干涉已有战争持续一轮；成功时干涉国随机一项 +0.5，失败随机一项 −1；被干涉国每面对一个干涉国随机一项 −0.5。

[试运行补充] 对战斗阶段开始已存在、在核／和平结算后仍存在的战争执行干涉；本轮新开的战争不能被干涉。每个有效干涉国当轮给被针对方随机一项 −0.5，并临时给支持方该场战力增加干涉国当前 `(C+E+M) × 0.25`。若战争当轮常规结算且支持方获胜，则干涉成功；若支持方未获胜（包括平局）则失败；战争当轮不结算时干涉不计成功或失败奖励，仅产生上述当轮效果。干涉加成不延续下一轮。战争被提前结束则干涉取消，不发生干涉声誉、伤害及成功／失败变化。这个成功条件、加成与未结算的处理均为补充，并非原文规定。

### 4.3 和平

[原文] 无战争时呼吁和平声誉 +1；战争中进攻方呼吁和平则战争立即停止、进攻方随机一项 −1，视为防守方获胜；防守方呼吁和平由双方谈判，进攻方所得不大于 3、防守方所失不低于 −3。

[试运行补充] 双方同时提出和平时，按进攻方和平处理一次。防守方求和先提出一个对该战争的和平方案，其对进攻方 C/E/M 正向增量之和不超过 3、防守方负向增量绝对值之和不超过 3；每项以 0.5 为单位。允许进攻方零收益和双方零增减方案，由进攻方决定是否接受；原文没有规定必须获得正收益。进攻方在单独谈判阶段选择接受或拒绝。接受则执行方案并结束该战争，不额外执行常规战果；拒绝、超时或无有效方案则无协议、战争继续。和平提议本身不阻止同轮核使用；优先顺序见第 5 节。没有参与任何战争时和平仅增加声誉；若参与其他战争但与目标无战争，和平不终止其他战争，仅增加声誉。

### 4.4 核使用

[原文] 核使用使目标一项 C/E/M −2。若存在战争，进攻方使用立即胜利、收益减半；防守方使用立即胜利、自身随机一项 −1、下一轮不得发动战争，该次不扣其声誉。

[试运行补充] 核使用仅有核国家可选，目标一项由引擎随机抽取；不自动发生二次打击、射程、命中率或核武数量消耗。核行动指向双方之间已经存在的战争时，选定一场结束：进攻方核使用获得其正常胜利收益 +0.5，目标核伤害 −2 照常发生，不另加常规防守失败 −2；防守方核使用者自身随机 −1 并禁下轮发动 `war`，目标核伤害照常发生，不另加常规进攻失败 −1。若两国间无战争，仅造成核伤害与声誉变化。若同一场战争双方同时核使用，两次核伤害都生效，但不适用单方核胜利奖励或防守方例外；战争结束，双方均按普通核使用扣声誉。多个核行动以同一快照同时结算，死亡检查在核批次结束后执行。

## 5. 同轮处理顺序与随机性

[试运行补充] 本节是保证一致性的实验选择：

1. 校验并冻结所有阶段提交；先处理针对同一场战争的同时核行动，按 4.4 结算核与战争终止，汇总该批数值变化并检查死亡。
2. 对仍存活国家与未结束战争处理和平；同场双方和平优先进攻方规则。防守方和平进行一次谈判。和平目标死亡或战争已被核结束时该项和平取消。
3. 处理仍合法的干涉和新开常规战争。对同一对国家同方向重复开战的情形按 4.1 限制；行动者或目标已死亡则取消。干涉伤害集中结算并检查死亡。
4. 对存活交战双方之间仍在进行、达到第二轮的战争，使用同一批次前快照计算胜负，并集中应用常规战果及干涉成功／失败收益，检查死亡；受死亡影响的战争结束且不补算胜负。
5. 对实际执行的行动计算声誉和可信度，统一截断；更新存续战争回合数，完成整轮后检查胜利、回合上限和环境总结。涉及已死亡国家的行动仍按其实际执行情况记录，其声誉与可信度可写入历史但不参与存活排名。

每项随机选择由规则引擎执行，记录种子、候选项和抽取结果；具体生成算法及版本随运行快照冻结。半点数值应使用整数半点或精确定点。行动、状态变化、取消原因、随机结果及事件可见性均须保存；确定性回放读取保存的决定和随机记录，不重新调用模型。

## 6. 明确的限制

原文未写完的例外、S/W 映射、并发冲突、和平谈判和部分可信度组合都已在本版以补充条款固定，**不是原文的唯一解释**。原文件没有授权将候选模型的推论当作原始规则，使用此版本前应请规则作者确认。原文的“国家可能会……”尚未完成，暂不推断后续内容。具体运行前应检查每国是否存在可选行动及目标；环境模型仅总结公开信息，不代替规则计算。
