# 整合说明

## 已确定的口径

最终项目位于 `strategic-multi-agent-game`。领域规则采用 `noclear/simulation_v2` 的 v4.1：C/E/M 相对开局净变化计分，资源变化成对转移，声誉和可信度仅作信号；领先第二名严格超过 5 分获胜，保留危机阶段与目标卡。

决策协议为 `sealed_v1`：预测、宣称、实际行动与谈判承诺在同一次决策包中提交。失败策略为 `peace_fallback_v1`：达到重试上限仍无有效包时，系统补充默认和平。版本记录同时包含基础规则、决策协议、失败策略、数据格式和代码/提示词指纹；与原 v4.1 两阶段实验分开识别。

## 每轮执行

1. 固定轮初状态，为每国构造其可见信息和合法选项；不包含对手当轮宣称或行动。
2. 并发收集每国一个决策包。各国独立重试，重试仅附本人输出的校验反馈。
3. 全部包有效或完成默认和平后统一揭示公开部分。
4. 读取已密封的谈判承诺，按 v4.1 执行资源转移、战争、危机及目标卡结算。
5. 保存状态、实际执行、默认和平标记、随机抽签、模型调用和公开事件，生成环境摘要及报告。

同轮提交后不再询问国家新的谈判选择。`offers` 模式的防守方预先选择 P1–P4 报价，进攻方预先提交愿意接受的方案 ID 集合。`self_offer` 模式的防守方预先填写 changes；进攻方预先给出 `accept` 布尔值、最低总收益及逐项最低收益，`accept=false` 表示拒绝全部报价。资源变化仍需逐项零和、0.5 步长并遵守 v4.1 的报价上限。接受条件不会接收对手当轮未揭示的报价后再修改。self_offer 的收益阈值按该次结算、资源上限截断后的实际所得匹配；offers 按预选方案编号接受，实际转移仍受上限约束。

## 共同数据接口

| 对象 | 统一字段与语义 |
| --- | --- |
| 国家 | `country_id` 是稳定引用，`name` 用于展示；`c/e/m`、`rep/cred`、`nuclear_status`、`alive` 保留 v4.1 语义 |
| 积分 | 开局 C+E+M 存为 `base_score`；`score` 为当前 C+E+M 减 base_score；rep/cred 不计分 |
| 行动 | `war/nuclear/intervene/peace`；`target_country_id`、`war_id`、`support_country_id` 引用稳定 ID |
| 战争 | `war_id`、`attacker_id`、`defender_id`、`started_round`、`progress_round`、`status`、胜者与结束原因 |
| 决策包 | 预测、宣称、行动、私有依据和谈判承诺；合法性基于同一个轮初状态 |
| 失败记录 | 保留尝试、错误类别、原始响应及补充行动来源；默认预测不作为模型有效预测参与评价 |
| 场景 | 国家数组、公共背景及来源 ID、私人观察、初始战争、危机、目标卡与规则版本 |

原三国场景的 `name` 按输入顺序映射为 C1、C2、C3，并保留 `migration.country_name_to_id`。`profile` 转为本国 `role_card`，原始画像另存为迁移元数据。英文核状态对应为：none→无、limited→有但打击能力有限、full→有、second_strike→二次核打击。

旧射程原文及映射后的国家 ID 保存在 `legacy_metadata`，不增加 v4.1 没有的军事能力/射程门槛。原三国场景不含危机，转换后也不生成危机或目标卡。己方原有场景的公共事实、来源 ID、私人观察、危机与目标卡保留。

## 迁移与兼容边界

代码结构使用可安装的 `src/strategic_game` 包。默认场景、知识库及提示词随包安装；运行结果写到工作目录，避免写入包安装目录。旧 CLI 的 `--mock --rounds` 和 `--output-dir` 形状保留，真实模型统一使用 provider 参数。

旧两阶段 run 与原三国输出保留原记录；`replay --show-only` 展示其保存摘要。新协议只回放版本相符的新记录，不通过修改旧版本标记将其冒充新实验。原有游戏规则文档保留为规则出处；执行顺序以本整合说明与记录中的协议版本为准。

固定种子用于规则随机数及选项顺序；当前真实模型请求不传 seed。规则回放使用已保存的决策和随机抽签核对状态，不承诺重新调用真实模型会得到逐字一致的输出。

默认和平继续进入规则结算，可能影响资源、危机解决及胜负。报告和完整记录必须能识别其系统来源；统计模型行为时需要报告其数量并按研究口径筛选。运行中发生无法安全结算的程序错误时仍保存失败记录，不能把部分写入的状态当作完成回合。

默认和平或环境摘要重试后仍失败时，运行状态为 `completed_with_errors`，CLI 返回非零退出码。环境摘要失败不增加国家默认和平计数，两者分别记录。

## 验收

- 七国默认场景与旧三国场景都可在安装后从其他目录加载。
- 国家引用、核状态和画像转换完整；没有隐式增加核门槛或危机。
- C/E/M 转移守恒、胜利门槛、战争时序和危机阶段按 v4.1 执行。
- 并发完成顺序不泄漏当轮信息，不改变已固定决策的结算结果。
- 非法 JSON、非法行动和请求失败达到上限后均记录默认和平，保存的补充决策可回放。
- 新运行保存后的决策、状态、随机抽签及最终结果可离线核对；旧协议运行被明确识别。
