# 游戏规则 v4.1（零和 + 危机阶段机）

- 日期：2026-10-29
- 状态：**试运行规则，等待规则作者确认**。v4.0 见 [游戏规则 v4.0](游戏规则-v4.0.md)；未列出的条款沿用 v4.0。
- 核心变化：在零和（C/E/M 净转移、总分恒 0、声誉/可信度不计分）之上，加入**危机阶段机**，让"不推进"持续付费，并让控制方从拖延中获益、挑战方被倒逼升级。

## 1. 危机阶段机

| 阶段 | 触发 | 持续 | 危机成本 | 升级 |
| --- | --- | --- | --- | --- |
| `crisis` 危机 | 开局（无当事国战争） | 至少 2 轮外交窗口 | 第 1–2 轮不扣分；第 3 轮起按等级扣分并转移给控制方 | 第 3/5/7/9 轮各升一级 |
| `war` 战争 | 当事国之间出现进行中战争 | 战争最长 2 轮 | **只按基础成本 0.5/轮固定收取** | 不升级 |
| `stalemate` 停滞 | 战争打平、谈判失败，或战争结束但未解决争端 | 直到解决 | 恢复全额，危机等级再 +1 | 之后仍按 3/5/7/9 轮升级 |
| `resolved` 解决 | 共同安排 / 战争胜者 / 谈判达成 / 当事国退出 | 本局结束 | 停止 | — |

- 前 2 轮为外交窗口：只记录、不扣分，给"共同安排/谈判"留时间。
- 第 3 轮起：每轮按 `crisis.unresolved_cost` 与当前等级产生成本；C/E/M 成本**转移给控制方**（零和），声誉/可信度只记录。
- 进入战争阶段：只按基础成本 0.5/轮固定收取，不随等级升级；战争打平/谈判失败 → 停滞阶段，成本恢复并按等级继续升级。
- 解决路径：双方当事国同轮相互和平（共同安排）、当事国之间战争出现胜者、谈判达成、任一当事国退出。
- 设计意图：**控制方希望拖延（持续获益），挑战方必须推进（开战/核/拉拢第三国）才能止损**。

## 2. 成本与等级

- 基础成本（场景可覆盖）：当事国 C −0.5/轮，依赖国 E −0.5/轮，其他方声誉信号 −0.2/轮（不计分）。
- 等级倍率：`escalation_multiplier`（默认 1.5），按 `level-1` 累乘；结果取 0.5 步长。
- 升级轮次：默认第 3、5、7、9 轮；停滞时额外 +1 级。
- 宽限期：默认 2 轮。
- 成本始终转移给控制方，因此控制方在危机中持续获益；挑战方若不推进，会持续失分并被倒逼使用战争/核/联合第三国。

## 3. 目标卡与阶段绑定

3.1 目标卡只在本方可见，条件可引用阶段与解决方式：

- `stage_is`：`crisis` / `war` / `stalemate` / `resolved`
- `resolution_is`：`agreement` / `war` / `negotiation` / `party_exit`
- `stalled_rounds_at_least`：停滞轮数阈值
- 原有 `control_is` / `crisis_resolved` / `crisis_level_at_least` / `attacked_by_any` / `war_any`

3.2 C/E/M 奖励/惩罚仍必须通过 `reward_from` / `penalty_to` 成对转移；声誉/可信度变化只作信号。

3.3 设计建议：把"控制权"目标绑定到 `resolution_is: war`，避免"共同安排"直接白拿控制权奖励；共同安排可以给"结束危机"类奖励，但不能替代战争结果。

## 4. 零和与校验

4.1 积分 = 当前 C/E/M − 开局 C/E/M；全员开局 0；全局总和恒为 0。
4.2 所有 C/E/M 变化均为转移；每轮结算记录 `score_sum`，非 0 告警。
4.3 和平行动本身不改变积分；危机成本、目标卡、谈判、战争、核、干涉都是转移。
4.4 声誉/可信度不进入积分，只作为公开信号。

## 5. 与 v4.0 的差异

| 条款 | v4.0 | v4.1 |
| --- | --- | --- |
| 危机成本起始 | 第 1 轮 | 第 1–2 轮外交窗口，第 3 轮起 |
| 阶段 | 无显式阶段 | crisis / war / stalemate / resolved |
| 战争阶段 | 成本照常 | 固定 0.5/轮、不升级 |
| 战争打平/谈判失败 | 成本继续 | 进入停滞、再升一级、全额恢复 |
| 升级轮次 | 3、6 | 3、5、7、9 |
| 目标卡条件 | 控制/解决/等级 | 增加阶段/解决方式/停滞轮数 |

## 6. 待规则作者确认

1. 战争阶段"固定 0.5/轮、不升级"是否符合预期；是否需要在战争阶段对依赖国/其他方也统一为 0.5。
2. 第 3/5/7/9 轮的升级节奏与 1.5 倍率是否过重；全 peace 基线是否出现集体死亡。
3. 控制方接收全部危机成本是否会让控制方"躺赢"过强；挑战方是否有足够手段（战争/核/联合第三国）改变现状。
4. 目标卡绑定 `resolution_is: war` 后，共同安排是否仍有足够吸引力。
5. 是否需要把声誉/可信度也做成交互转移（当前不做）。
