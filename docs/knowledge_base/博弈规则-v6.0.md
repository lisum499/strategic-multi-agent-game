# 博弈规则 v6.0

v6.0 保留 v5.0 的同时密封决策、冲突累计、核门槛、战损、盟约和确定性回放机制，以全球存在指数（IPG）完全替代旧领土资源。

## 国家存在状态

每个国家有三个权威状态，场景初值均为 0 至 100：

- `economic_presence`：经济网络、市场、供应链和资源影响。
- `military_presence`：基地、部署、投送和持续军事影响。
- `soft_presence`：制度、外交、文化、规范与舆论影响。

全球存在指数为派生值：

```text
IPG = 0.43 * economic_presence
    + 0.21 * military_presence
    + 0.36 * soft_presence
```

模型和场景不能直接设置 `global_presence`。程序在验证场景和每次结算后统一计算。借入常规或核力量只增加当轮可投入力量，不直接增加军事存在。

## 军事能力、投送与二次打击

场景只设置初始 `conventional` 和 `nuclear`，`nuclear_status` 已从系统删除。常规力量为0–39时，开局核力量必须为0；常规力量达到40后才可在开局将核力量设为1–100。开局后常规力量变化不会自动增加核力量。

当前公开 `nuclear` 直接决定核权限：`0` 不能选择核行动；`1–40` 只能选择门槛值低于45.0的核行动；`>=41` 可以选择所有核行动并具备自动二次打击。借调、归还和战损会动态改变该权限。实际核使用仍须投入大于0的核力量。旧 `power_m` 已从程序状态中删除。

系统不保存国家区域或国家间距离，核行动不检查地理范围。实际核行动要求核力量、冲突门槛和核行动区间均合法；核信号及威胁不视为实际核使用。

“行动门槛”是本轮开始时行动方对特定目标的有向累计冲突值。A 对 B 选择核行动时只检查 `conflicts[A][B]`，不能用 `conflicts[B][A]` 代替，也不能用该核行动在本轮即将增加的数值补足自身门槛。默认门槛为：

| 核行动 | 轮初最低有向冲突值 |
| --- | ---: |
| 核信号释放 | 12.5 |
| 核军事预备 | 17.5 |
| 核武器示威 | 25 |
| 核威胁 | 35 |
| 有限核武器使用 | 45 |
| 升级性核行动 | 57.5 |
| 扩大核打击行动 | 72.5 |
| 战略核威胁 | 85 |
| 最后核警告 | 95 |
| 战略核战争 | 100 |

这些门槛取自 `rules.json` 的 `actions`，场景覆盖 `rule_config.actions` 时以实际配置为准。达到门槛只获得选择资格，不会自动执行核行动。四项实际核使用还必须满足当前核力量大于0且实际投入核力量大于0；其余核信号、示威和威胁不属于实际核使用。

具备二次打击能力的国家遭受“升级性核行动”“扩大核打击行动”或“战略核战争”时，主持人从受保护核力量中按 `second_strike_reserve_fraction` 提取报复规模，默认25%，在多个触发者间平均分配。有限核武器使用仍属于实际核使用并参与核战损、核使用历史和正常结算，但不触发自动二次打击。自动报复镜像攻击者的触发行动等级，进入相同的冲突、IPG和战损结算；国家已经主动对同一攻击者实施任一实际核行动时，不重复生成自动报复。事件保存于 `automatic_second_strikes`。

## 战略文化状态

每个国家必须在顶层设置 `strategic_culture`，可选国际主义、民族主义、进步主义、现实主义。该状态公开且在游戏中保持不变，不直接改变冲突、战损或IPG公式。主持人将文档中的完整定义提供给模型，并要求国家结合本国战略文化解释评估、预测和行动理由。旧的 `tags.strategic_culture` 写法不再接受。

## 意识形态侧重性状态

每个国家必须在顶层设置 `ideology_focus`，取 1–10 的整数。1 表示对维护或推广意识形态淡漠，10 表示狂热侧重，数值越大侧重程度越高。高侧重国家在提示词中被要求更多考虑原则一致性、意识形态差异和改造外部世界；低侧重国家更多考虑安全、利益和跨制度合作。该状态公开、开局后固定，不直接改变冲突、战损、IPG或行动门槛。旧的 `tags.ideology` 写法不再接受。

## 私人利益攸关方

国家可在私人 `tags.stakeholders` 中设置 `allies`、`adversaries`、`others` 国家 ID 数组和 `description` 补充描述。它表示本国的利益攸关方设定或认知，只对本国 Agent 可见，不会自动建立真实联盟或修改结算。`tags` 不接受其他字段；知识词典中的旧画像内容仅用于追溯原始资料，不是可配置运行状态。

## 联盟公开条件

规则层面的联盟成立后默认只对双方可见。仅当一方从同一盟友实际借入且尚未归还的 `conventional` 或 `nuclear` 中，任一项累计达到 1 时，联盟状态强制公开。多次小额借调会累计计算；联盟一旦公开，不会因后续归还而恢复秘密。联盟合同、借调事实及具体数值始终只对双方可见。

邀请或接受联盟时，与第三国有关的限制只检查受邀方现有的公开盟友。秘密盟友不会触发该限制；邀请双方自己已经结盟时仍不能重复结盟。公开联盟终止会产生公开事件，秘密联盟终止只通知相关双方。

## 冲突优势与存在转移

双边累计冲突值、行动增量和核行动系数沿用 v5.0。累计值差乘核系数后得到本轮 IPG 优势。程序按胜方本轮行动类型把该优势分配到三个存在维度：

| 行动类型 | 经济 | 军事 | 软实力 |
| --- | ---: | ---: | ---: |
| 保持、撤退或投降 | 43% | 21% | 36% |
| 外交 | 10% | 0% | 90% |
| 经济 | 80% | 0% | 20% |
| 常规军事 | 20% | 70% | 10% |
| 核行动 | 40% | 50% | 10% |

这里的百分比是 IPG 收益份额。引擎会除以相应 IPG 系数，换算为各存在维度的实际转移量，因此资源充足时三个维度的加权变化之和恰好等于本轮 IPG 优势。

同一支付方按经济、军事、软实力三个维度分别结算；同维度面对多个胜方时按请求比例分配，不足则降至 0。支付方按国家 ID 稳定排序，退场受益方的份额退回支付方。全部结算均记录在 `presence_transfers` 中。

## 退场与胜利

- IPG 降至 0 的国家退场。
- 仅剩一个在场国家时，该国获胜。
- 国家 IPG 达到 `ipg_win_min`，且领先第二名至少 `ipg_win_gap` 时，以 `ipg_victory` 获胜。
- 默认门槛分别为 50 和 30，可由场景 `rule_config` 覆盖。
- 第 30 回合结束仍无人满足胜利条件，或所有国家同时退场时，无胜者。投降按本轮所有在场国家统一判断：如果除目标国外的所有在场国家都向该目标选择“完全投降”，目标国获胜；只要有一个其他在场国家未向该目标投降，任何投降者都不退场，视为暂时苟和。只有本轮开始时恰好剩余两个在场国家且双方互相完全投降，才以无胜者结束；三个或更多在场国家中的任意一对互相投降不直接结束游戏。

## 兼容性

v6.0 场景必须声明 `rules_version: "v6.0"`。旧 `territory` 字段、旧 v5.0 场景和 v5.0 精确回放均不由 v6 引擎兼容处理；旧记录只能用 `--show-only` 查看，或切回对应 Git 版本重算。
